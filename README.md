# Site_Instituto_Raizes

#  Meu Primeiro Projeto Web

---

## 📂 Conhecendo os arquivos

🏠 **`index.html` — Página inicial**

É a porta de entrada do site! Aqui ficam as informações iniciais e os links para navegar entre as páginas.

📝 **`cadastro.html` — Página de cadastro**

Uma página destinada ao preenchimento de informações do usuário, como nome, e-mail e outros dados.

💼 **`projetos.html` — Página de projetos**

Espaço dedicado à apresentação de projetos, trabalhos e ideias desenvolvidas durante minha jornada de aprendizado.

---

## 🛠️ Tecnologias utilizadas

- 🌐 **HTML:** responsável pela estrutura e organização das páginas.
- 💻 **Visual Studio Code:** editor utilizado para escrever e organizar o código.
